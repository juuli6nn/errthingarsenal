<h2>⚽ About the Project</h2>
<p>
<b>ErrthingArsenal</b> is a fan-made website dedicated to everything about Arsenal Football Club.
It aims to provide an engaging and modern platform where fans can explore content, updates, and features centered around the club.
</p>

<p>
This project is currently focused on building a clean and interactive frontend using modern tools like React and TypeScript.
</p>

<hr>

<h2>🚀 Features (So Far)</h2>
<ul>
  <li>⚛️ Built with React + TypeScript</li>
  <li>🎨 Custom styling using CSS</li>
  <li>📱 Responsive layout (in progress)</li>
  <li>🧱 Component-based architecture</li>
  <li>🔥 Passion-driven UI focused on Arsenal fans</li>
</ul>
